# 116 大學選系（申請＋分發）

給 116 學年度（2027 年入學）大學「個人申請」和「分科測驗／分發入學」用的選系工具：同一個系，申請和分發兩條路各看得到。網址和 repo 名稱還是 `apply-116`。六個分頁，照使用順序排：

1. **我的成績**：選一份成績看落點——自己填的學測級分（或目標分數），或任何一次存下來的模考。每份成績一張卡，各科對齊排成一列、標出是哪一標，一眼就能比較。選好的那份，找校系、我的志願、怎麼進步都用它，每頁最上面的「落點依據」寫著現在用哪一份，也可以直接切換。
   - **沒考的科目到處都不列**：學測級分設為沒考的科目（例如數A），模考裡填了也不列出、不計算（翰林第一、二次數A、數B 同一份考卷，很多人兩格都填）。數A/數B 擇一的檢定，只寫你考的那科。
   - **學測級分**：拖曳格子填級分，下面馬上顯示落點分布。APCS、檢定用哪一年的五標（113–115 或自訂，例如 116 公布後）收在「更多」裡。
   - **模考**：選翰林哪一次（7月全國、9月北北基＝北區、10月北北基＝北區；中區「中模」、南一全國是不同考試，選「其他模考」自己填五標），日期和五標自動帶入，直接打級分，每科標出是哪一標、照排名換算成學測約幾級分。用模考看落點時，**檢定用那次模考的五標**比你的模考級分；**倍率篩選**用換算的學測級分比 115 門檻（115 門檻是學測級分）。
   - **分科成績（想走分發的話）**：每科選「不考／估計／自己填」（0–60 級分）。估計＝你的學測（或模考換算的學測級分）在 115 分發考生裡排前幾 %，就當你在 115 分科考生裡也排那裡（數A → 數甲、數B → 數乙、自然 → 物化生、社會 → 歷地公）；分科只考一科、範圍更深，只是粗估。學測 g 級分在分發是 60 級分制的 4g−3～4g（兩種級分切的是同一個原始分數）。
   - **落點分布＝兩條路並排**：申請入學（一階）和分發入學（學測＋分科加權總分 vs 115 最低錄取分數）各一條，各有幾個系穩過或應該過、最搶手的是哪些、只有哪條路有機會的有幾個，再給一句建議（用同一把尺：同一個系在申請的 115 一階門檻）。展開還有兩條路的差別，和你每科在 115 分發考生（學測）、分科考生裡排前幾 %。
   - **落點分布**：跟找校系同一組篩選（也可以在這裡打開篩選、切換「申請＋分發／只看申請／只看分發」）。
   - **為什麼兩條路結果不一樣？**：兩條路各自被哪些檢定、哪些沒考的科目擋住最多系，以及每一科多或少 1 級分，申請和分發的「穩過＋應該過」各變多少（例如國文剛好在均標時，少 1 級分申請會掉一大批、分發只掉一點：申請的檢定是一刀切，分發是加權總分，一科低可以用別科補）。
   - **完整報告（可給 AI）**：一份 Markdown 文字報告，包含成績和排名、歷次模考、分科估計、興趣測驗、整體落點、最有機會的學群、每個志願的每一關門檻和你的級分、審查資料準備狀況、志願檢查、怎麼進步、其他可以考慮的校系。可以選擇開頭加上給 AI 的說明（請它分析處境、檢查志願、排出接下來要做的事，而且不要編造報告沒有的數字），複製、下載 .md 或分享，貼給老師、家長或 ChatGPT／Claude／Gemini。報告沒有姓名或學校。
   - **還不確定讀什麼？**：各科在 115 考生排第幾 %，再看每個學群有幾個系你穩過或應該過、一階最常篩哪些科目（你的強項會亮起來），依「有機會的比例＋科目合不合你」排序。可以選高一大考中心興趣量表的結果（R 實用、I 研究、A 藝術、S 社會、E 企業、C 事務），符合的學群排前面（對應只是大致參考）。沒做過可以直接在站內做**興趣測驗**：48 個活動一題一題回答喜不喜歡（約 5 分鐘、不用上網），算出每一型的平均和前三碼，一鍵套用到學群排序。題目是 Armstrong, Allison & Rounds (2008) 公開發表、經效度研究的 RIASEC Markers（活動 A 組，每型 8 題），中文為本站翻譯、沒有台灣常模，只當探索起點，不能取代學校的大考中心興趣量表。按一個學群，就到找校系列出那個學群你穩過＋應該過的系，去年門檻高的在前。
   - **模考進退步**：一張表，每科每次模考換算成學測級分比較（每次難度不同，原始級分不能直接比），附那次的標和整體變化；分數和排名走不同方向時會提醒（這次比較難或比較簡單）；每次模考各自的落點（各用各的五標）。
   - 存一次新模考就會自動改用它；學測級分不會被模考蓋掉。
2. **找校系**：左邊只有篩選（範圍：全部／收藏／志願、學群、學校、一階學測怎麼篩、二階怎麼甄選、特殊組別），右邊是結果。這組篩選全站共用：我的成績的落點分布、每次模考的落點、怎麼進步都照它算；「申請＋分發／只看申請／只看分發」也一樣。
   - **搜尋**：學校和系可以黏在一起打（東吳法律、政大企管、台大資工），台／臺都可以，系的簡稱照字的順序對（資工＝資訊工程、財金＝財務金融、外文＝外國語文）；名稱符合的排在只有說明裡提到的前面。
   - **逐關檢查一階**：檢定（數A/數B 擇一）→ 每一關倍率篩選都對照 115 年的最低級分 → 最後一關同分提醒看超額篩選。
   - **申請＋分發一起看**（預設）：每個系同時標出申請一階和分發（116 分發 1,777 系組，考分會校系分則）的落點，用比較有機會的那條排序和篩選——申請過不了、分發有機會的系也會留著。也可以只看申請或只看分發；只有分發的系組（申請沒招）也會列出。分發：每科平均比 115 最低多 2.5 級分以上＝穩過、過 115 最低＝應該過、差 2.5 以內＝邊緣；檢定沒過或沒考要用的科目＝過不了；術科或 116 新系組＝看不出；116 採計跟 115 不同的系門檻照總權重換算、不標穩過；116 最低登記標準 7/29 才公布，沒算。詳細頁也列出同一個系在分發的採計和你的落點。
   - **排序**：每個選項都是「依什麼：方向」——落點（穩過在前，同一級裡去年門檻高的在前）、去年門檻（高 → 低＝熱門的在前，低 → 高＝好進的在前）、二階學測佔比、甄試日期、名額、校系代碼。選單下面一行說明目前的排法。
   - **判斷落點**：每個系回答「一階過得了嗎？」——穩過／應該過／邊緣／機會低／過不了／看不出，配訊號格一眼看出；點標籤可以隱藏或顯示。
   - **只看一階用得到你的科目**：可以選「不要用到這些科目」（例如不要數A），檢定或倍率篩選用到它的系就不列出（數A/數B 檢定擇一的，兩科都選才隱藏）。倍率篩選或二階採計用到你沒考的科目（依簡章以 0 級分計）的系預設也隱藏。
   - **哪組科目對你最有利**：列出一階用來篩選的科目組合（國英社、英數A自…），每個都寫你在這組排 115 考生前幾 %，最強的排前面，點一下只看用這組篩選的系。
   - **二階**：可以只看「二階不計學測」「學測佔 20% 以下／50% 以上」「不用面試」「不用筆試」「不用到校甄試」的系；點進去看二階總成績怎麼組成、要交哪些審查資料。
3. **我的志願**：排六個志願，檢查穩衝搭配、甄試撞期、同校擇一報名、費用；**我的學習歷程**（勾你已經有的課程學習成果、多元表現，和寫好的自述，列出志願還會看、你還沒有的，以及每個志願準備到哪；系列出的是會看的種類，不用每種都有）；二階要準備什麼（總成績組成、六個志願的審查資料對照表，標出你已經有的）；二階行事曆；完整報告、複製文字、CSV、列印；換裝置與備份。
4. **怎麼進步**：跟找校系、我的成績用**同一組篩選**（學群、地區、公私立、一階／二階條件、關鍵字，加上「全部／只看收藏／只看志願」），在哪一頁改都一樣，也可以直接在這頁打開篩選。最值得補強的一科；每科多考 1–5 級分會多出幾個校系（附模考趨勢）；哪個檢定擋住你最多系；試算（暫時改級分看落點怎麼變）。用模考時，從換算的學測級分往上加，檢定照那次模考的五標同步加減。
5. **考古題**：大考中心公布的 111–115 學年度（108 課綱）學測和分科歷屆試題，共 67 份考卷（國寫除外）。
   - **練習**：不限時，每題作答後可以馬上對答案；**模擬考**：照正式考試時間倒數，交卷才看答案和分數（時間到自動交卷）。**小測驗**：同一科 111–115 年的選擇（填）題隨機出 10／20／40 題。
   - 作答像在考卷上：每個選項旁邊的 ✕ 可以刪去選項（刪掉的劃線變淡），可以標記題目、用題號列表跳題（看得出哪些寫了、標記了）；題組的文章在旁邊（電腦）或上面（手機，可以捲動），文意選填的空格會在文章裡標出來；選填題用格子加鍵盤（0–9、－、±）填。
   - 計分照大考中心的規則：單選全對才給分；多選每個選項獨立判定，錯 k 個得 (n−2k)/n；選填每一格都對才給分。交卷後有總分、逐題對照和逐題檢討；答錯的題目進**錯題本**，可以只練錯題。這是原始分數，不是級分。
   - **非選擇題（可以不做）**：預設跳過；打開「模擬考包含非選擇題」後，每題可以寫下作答、按一下把題目、大考中心的評分原則和你的作答複製給 AI（ChatGPT、Claude、Gemini…），請它照評分原則打分數，再把分數填回來算進總分。
   - 題目是從大考中心的 Word 試題轉出來的文字：公式（MathType）轉成 MathML，用瀏覽器排版，手機上也清楚、可以放大；選填的答案格（Word EQ 功能變數）照原本的樣子畫出來。用 Word 圖形畫的圖、統計圖表等轉不出來的題目，直接用官方 PDF 試卷的截圖，所以不會顯示錯。
   - 每份考卷是一個獨立的小檔案（`docs/exams/`），打開那份才下載，主頁面不會變大。
6. **時程與規則**：116 官方日程（含倒數）、一定要知道的規則、落點怎麼判斷、審查資料代碼表。

整個工具是**一個 HTML 檔**（約 1.7 MB，網路傳輸約 1.1 MB），資料全部內建，不用網路、不用安裝，手機和電腦都能用。

- 線上版：GitHub Pages（`docs/index.html`）
- 離線版：下載 [`docs/index.html`](docs/index.html)，用瀏覽器打開就好。

你的成績、收藏和志願只存在自己的瀏覽器（localStorage），沒有帳號、沒有伺服器。**換裝置**（我的志願 → 換裝置／備份）：
- **傳連結給自己**：資料壓縮後放在連結的 `#import=` 後面（瀏覽器不會把 # 後面送到伺服器），用 LINE、AirDrop、Email 傳給自己，在另一台打開會先列出帶進來的內容，確認後才取代。
- **轉移碼**：同一段壓縮碼（一般幾百到一兩千字），在另一台貼上匯入。
- **備份檔**：下載 JSON 檔，之後再選回來。

## 落點怎麼判斷

一階篩選的官方規則（教育部《116 學年度大學多元入學學生手冊》）：先檢定；倍率從大到小一關一關篩；**中間關卡同級分的人全部進下一關，只有最後一關同分才用「同級分超額篩選」**。所以每一關都要達到，最後一關剛好相等是碰運氣。

**以 116 的篩選為準。** 每個校系照 116 校系分則排出一階關卡（倍率相同的科目加總成一關），每一關只拿 115 **用同樣科目篩選**的最低級分來比。116 改用 115 沒篩過的科目或組合（例如 115 篩國英數B社、116 篩國英社），115 的門檻就不能拿來比，那一關會寫「115 沒有同樣科目的門檻」，校系判「看不出」。116 拿掉的 115 關卡不算。

**模考也一樣比，但檢定用那次模考的五標。** 例如 10月北北基英文均標是 6 級分（115 學測是 8），模考英文 6 就算過「英文均標」檢定。倍率篩選的 115 門檻是學測級分，所以模考級分先照排名換算：模考五標各對應一個排名（頂標前 12%、前標 25%、均標 50%、後標 75%、底標 88%），中間的級分照比例插，再從 115 級分人數累計表找同排名的學測級分。這只是估計，模考考生和範圍跟學測不同。沒有那次五標的科目，檢定改用學測五標、篩選用原始級分。

**收的人數變了就換算。** 一關大約收「倍率 × 招生名額」人。116 這一關收的人跟 115 差超過 10%，就用大考中心 115 級分人數累計表換算：排在你前面的人要在 116 收的人數內。例如 115 英文 ×10、名額 27（約 270 人），116 英文 ×3、名額 26（約 78 人），門檻會比 115 高很多，剛好過 115 最低不夠。倍率改了但名額也跟著改、人數差不多的，115 門檻照樣可以比。用同系別組資料的校系名額不能比，不換算。

每個校系只回答一個問題：**一階過得了嗎？** 標籤前面有訊號格（4 格最穩），先看格數就知道。

| 標籤 | 訊號 | 意思 | 判斷規則 |
|---|---|---|---|
| 穩過 | ▮▮▮▮ | 去年門檻再漲也過 | 每一關都高於 115 最低，最後一關至少高 2 級分（門檻漲 1 也還會過），而且依 115 級分人數累計表（人數變了就換算），排在你前面的人 ≤ 排在門檻前面的 75%。116 不用倍率篩選的，通過檢定就是穩過 |
| 應該過 | ▮▮▮ | 過得了去年門檻，但差距小 | 每一關都達到，但差距小，或 116 篩選有改（見下） |
| 邊緣 | ▮▮ | 卡在去年門檻上下 | 剛好等於最後一關（看超額篩選），或低於門檻（人數變了就是換算後的門檻）但排在你前面的人不超過門檻的 1.4 倍 |
| 機會低 | ▮ | 比去年門檻低不少 | 排在你前面的人超過門檻的 1.4 倍 |
| 過不了 | ✕ | 一定進不了一階 | 檢定沒過，或系用到的學測科目（檢定、篩選、採計）你全部沒考（簡章：總和 0 級分不得參加篩選）。只沒考其中一科，那一科以 0 級分去比，通常是「機會低」 |
| 看不出 | ? | 去年沒有能比的門檻 | 116 用 115 沒篩過的科目或組合、116 新設／改名，或只用術科篩選（都會寫原因） |

以下情況最多判「應該過」並寫出原因：116 倍率改了而收的人數差超過 10%（或用的是同系別組資料、人數沒辦法比）；116 篩選順序跟 115 不同；116 拿掉了 115 的某一關；用的是同系別組或名稱相近系組的資料；預計甄試人數比 115 少 15% 以上；換成 113 或 114 年五標你會檢定不過。

這只是一階能不能過的估計，不是錄取機率。

### 資料檢查（`npm test` 會跑）

- 每個校系的學測參採科目組合，跟甄選會 2026-10-27 公布的「116 申請入學各校系參採學測科目一覽表」**完全一致**（49 種組合、2,240 校系）。

- 每一筆 115 對應都指向官方分發標準一覽表裡真的存在的 115 校系，名稱不同的一定有標註。
- 舊版比對有 3 筆配錯（臺南大學體育/教育公費生、北市大教育/體育公費生、臺藝大擦弦/彈弦組），已移除並標明原因。
- 沒有 115 資料的 107 個校系，每一個都寫了原因；名稱相近的去年校系只當提示，不拿來算落點。

## 開發

```bash
pip install xlrd            # 只有重新解析官方 xls 時需要；也需要 poppler-utils (pdftotext)
npm run data                # 官方原始檔 → data/official/*.json → build/app-data.json
npm ci                      # esbuild（壓縮 JS、CSS）
npm run build               # → dist/index.html 與 docs/index.html（單一檔案）
npm test                    # 邏輯與資料測試（node --test）
npm run test:e2e            # 瀏覽器測試（Playwright Chromium；擋掉所有網路請求）

# 考古題（需要 LibreOffice、poppler-utils、pdfplumber、Pillow、lxml）
python3 scripts/fetch_exams.py   # 大考中心 111 年起的試題 docx、PDF、答案、評分原則 → data/raw/exams/（約 300 MB，不進 git）
python3 scripts/parse_exams.py   # → docs/exams/<id>.js（每份考卷）、docs/exams/img/、docs/exams/index.json
```

```
src/logic.js     落點規則（純函式，瀏覽器與 Node 共用）
src/app.js       介面
src/exam.js      考古題（練習、模擬考、計分、錯題本；考卷用 <script> 載入 exams/<id>.js，下載後離線打開也能用）
src/index.html   版面；build 時把 CSS、JS（esbuild 壓縮）和資料（gzip＋base64，頁面用 DecompressionStream 解開）內嵌進來
src/vendor/      tiny-inflate（MIT）：沒有 DecompressionStream 的舊瀏覽器（iOS 16.4 以前）解資料用
scripts/         資料處理（parse_official.py、fetch_uac.py、parse_uac.py、build_data.py、build.mjs；fetch_exams.py、parse_exams.py、mtef.py（MathType → MathML）是考古題；legacy/ 是 115 圖片判讀時的程式）
tests/           單元、資料、瀏覽器測試
```

116 學測成績與五標 2027/2/25 公布後：在工具裡把「檢定用五標」改成 116（需要先把 116 五標加進 `data/raw/ceec115/p26.xls` 的新版並重跑 `npm run data`）。
