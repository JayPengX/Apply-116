# 116 申請入學選系工具

給 116 學年度（2027 年入學）大學「個人申請」用的選系工具。輸入學測級分，它會：

- **逐關檢查一階**：檢定（數A/數B 擇一）→ 每一關倍率篩選都對照 115 年的最低級分 → 最後一關同分提醒看超額篩選。
- **判斷落點**：穩／適中／衝／難／不符／無資料，每一格都寫出理由。
- **排六個志願**：檢查穩衝搭配、甄試撞期、同校擇一報名、費用，列出你自己的二階時間表。
- **看二階要準備什麼**：每個系的二階總成績怎麼組成（學測佔幾 %、審查資料、面試、筆試）、要交哪些審查資料；可以只看「二階不計學測」「不用面試」「不用到校甄試」的系；志願頁把六個志願要交的審查資料排成一張對照表。
- **只看一階用得到你的科目**：可以選「一階不用」哪些科目（例如不要數A），檢定或倍率篩選用到它的系就不列出（數A/數B 檢定擇一的，兩科都選才隱藏）。倍率篩選或二階採計用到你沒考的科目（依簡章以 0 級分計）的系預設也隱藏，可以在篩選裡打開。
- **看哪個科目組合對你最有利**：篩選裡列出一階用來篩選的科目組合（國英社、英數A自…），每個都寫你在這個組合排 115 考生前幾 %，照強弱排，點一下只看用這個組合篩選的系。
- **自訂五標**：檢定可以改用自己填的五標（例如模考公布的），不一定要用 113–115 學年度的。
- **模考**（自己的分頁）：選哪一次翰林模考，日期和五標自動帶入（內建第二次各科、第一次數學的五標，其他照成績單填，一科五格都填才算），直接打級分，每科馬上標出是哪一標。分析：最近一次每科的標和「再幾級分到下一標」、跟之前比（進步、退步、級分和標不同方向）、每科趨勢圖、每次的落點和成績表；「用這次成績看落點」一鍵換到找校系。
- **告訴你怎麼進步**：每科多考 1–5 級分會多出幾個校系；哪個檢定擋住你最多系；可以試算。
- **時程與規則**：116 官方日程（含倒數）、一定要知道的規則、審查資料代碼表。

整個工具是**一個 HTML 檔**，資料全部內建，不用網路、不用安裝，手機和電腦都能用。

- 線上版：GitHub Pages（`docs/index.html`）
- 離線版：下載 [`docs/index.html`](docs/index.html)，用瀏覽器打開就好。

你的成績、收藏和志願只存在自己的瀏覽器（localStorage），不會上傳。可以「備份我的資料」換裝置。

## 落點怎麼判斷

一階篩選的官方規則（教育部《116 學年度大學多元入學學生手冊》）：先檢定；倍率從大到小一關一關篩；**中間關卡同級分的人全部進下一關，只有最後一關同分才用「同級分超額篩選」**。所以每一關都要達到，最後一關剛好相等是碰運氣。

**以 116 的篩選為準。** 每個校系照 116 校系分則排出一階關卡（倍率相同的科目加總成一關），每一關只拿 115 **用同樣科目篩選**的最低級分來比。116 改用 115 沒篩過的科目或組合（例如 115 篩國英數B社、116 篩國英社），115 的門檻就不能拿來比，那一關會寫「115 沒有同樣科目的門檻」，校系判「無資料」。116 拿掉的 115 關卡不算。

**收的人數變了就換算。** 一關大約收「倍率 × 招生名額」人。116 這一關收的人跟 115 差超過 10%，就用大考中心 115 級分人數累計表換算：排在你前面的人要在 116 收的人數內。例如 115 英文 ×10、名額 27（約 270 人），116 英文 ×3、名額 26（約 78 人），門檻會比 115 高很多，剛好過 115 最低不夠。倍率改了但名額也跟著改、人數差不多的，115 門檻照樣可以比。用同系別組資料的校系名額不能比，不換算。

| 落點 | 意思 |
|---|---|
| 穩 | 每一關都高於 115 最低，最後一關至少高 2 級分（門檻漲 1 也還會過），而且依 115 級分人數累計表（人數變了就換算），排在你前面的人 ≤ 排在門檻前面的 75%。116 不用倍率篩選的，通過檢定就是穩 |
| 適中 | 每一關都達到，但差距小 |
| 衝 | 剛好等於最後一關（看超額篩選），或低於門檻（人數變了就是換算後的門檻）但排在你前面的人不超過門檻的 1.4 倍 |
| 難 | 明顯低於門檻 |
| 不符 | 檢定沒過，或系用到的學測科目（檢定、篩選、採計）你全部沒考（簡章：總和 0 級分不得參加篩選）。只沒考其中一科，那一科以 0 級分去比，通常是「難」 |
| 無資料 | 沒有可以比的 115 門檻：116 用 115 沒篩過的科目或組合、116 新設／改名，或只用術科篩選（都會寫原因） |

以下情況最多判「適中」並寫出原因：116 倍率改了而收的人數差超過 10%（或用的是同系別組資料、人數沒辦法比）；116 篩選順序跟 115 不同；116 拿掉了 115 的某一關；用的是同系別組或名稱相近系組的資料；預計甄試人數比 115 少 15% 以上；換成 113 或 114 年五標你會檢定不過。

這只是一階能不能過的估計，不是錄取機率。

### 資料檢查（`npm test` 會跑）

- 每個校系的學測參採科目組合，跟甄選會 2026-10-27 公布的「116 申請入學各校系參採學測科目一覽表」**完全一致**（49 種組合、2,240 校系）。
- 115 五標跟大考中心成績標準一覽表一致；級分累計表每一列都能加總對上。
- 每一筆 115 對應都指向官方分發標準一覽表裡真的存在的 115 校系，名稱不同的一定有標註。
- 舊版比對有 3 筆配錯（臺南大學體育/教育公費生、北市大教育/體育公費生、臺藝大擦弦/彈弦組），已移除並標明原因。
- 沒有 115 資料的 107 個校系，每一個都寫了原因；名稱相近的去年校系只當提示，不拿來算落點。

## 開發

```bash
pip install xlrd            # 只有重新解析官方 xls 時需要；也需要 poppler-utils (pdftotext)
npm run data                # 官方原始檔 → data/official/*.json → build/app-data.json
npm run build               # → dist/index.html 與 docs/index.html（單一檔案）
npm test                    # 邏輯與資料測試（node --test）
npm run test:e2e            # 瀏覽器測試（Playwright Chromium；擋掉所有網路請求）
```

```
src/logic.js     落點規則（純函式，瀏覽器與 Node 共用）
src/app.js       介面
src/index.html   版面；build 時把 CSS、JS、資料內嵌進來
scripts/         資料處理（parse_official.py、build_data.py、build.mjs；legacy/ 是 115 圖片判讀時的程式）
tests/           單元、資料、瀏覽器測試
```

116 學測成績與五標 2027/2/25 公布後：在工具裡把「檢定用五標」改成 116（需要先把 116 五標加進 `data/raw/ceec115/p26.xls` 的新版並重跑 `npm run data`）。
